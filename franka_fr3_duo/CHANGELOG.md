# Changelog – Franka Robotics FR3 Duo Description

All notable changes to this model will be documented in this file.

## [2026-11-07]

- Initial release of the Franka Robotics FR3 Duo MJCF model.
- Model features dual arm-only Franka Research 3 (FR3 v2) robotic arms mounted
  on the dual-arm table mount (`fr3_duo_mount_v0_3`) with sensor head
  (`franka_head_v0_2`), plus an optional floor-standing column variant
  (`fr3_duo_with_spine.xml`, `franka_spine_v0_1`).
- Derived from `frankarobotics/franka_description` version 2.9.0.
